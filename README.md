# The Bazaar for webOS TV

A simple full-screen webOS app that opens The Bazaar directly. The app loads the site as a top-level page so its sign-in form and TV-side session cookie work; it does not embed the site in a frame or collect credentials.

## Install or update

In Homebrew Channel, refresh the existing repository and choose Update for The Bazaar (app ID `com.homeframe.launcher`). The repository URL remains:

`https://raw.githubusercontent.com/dalienthealien88/LGTVHOMESCREEn/main/repo.json`

## Sign in

Sign in on the TV when the Bazaar page opens. The TV has its own browser session; signing in on a desktop does not sign the TV in. The NAS page uses HTTP, so use it only on a trusted home network.
