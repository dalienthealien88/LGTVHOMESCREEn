# The Bazaar for webOS TV

A full-screen webOS app with a remote-friendly sign-in form. It submits sign-in directly to The Bazaar server; successful login opens the compatibility home. The app does not store passwords.

## Install or update

In Homebrew Channel, refresh the existing repository and choose Update for The Bazaar (app ID `com.homeframe.launcher`). The repository URL remains:

`https://raw.githubusercontent.com/dalienthealien88/LGTVHOMESCREEn/main/repo.json`

## Sign in

Use the remote arrows to focus Username and Password, press OK to type, then select Sign in. The TV keeps its own Bazaar session; desktop browser sessions are separate. The NAS page uses HTTP, so use it only on a trusted home network.
